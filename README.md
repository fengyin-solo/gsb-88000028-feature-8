# solo-8800002

一个基于 Vite + Vue 3 的纯前端小众业务示例项目，主题是古籍虫蛀修复批次管理。

## 开发

```bash
npm install
npm run dev
```

`vite.config.js` 已显式配置 `server.open = false`，启动开发服务时不会自动打开浏览器。

## 构建

```bash
npm run build
```

## 测试

```bash
npm test
```

使用 Node 内置测试运行器验证待处理批次提醒的分级逻辑：重复标记去重、容量数据缺失时不加权不升级、处理后数量联动等。

## 功能说明

- 待处理批次提醒按积压时长、风险等级和修复室容量分为紧急 / 优先 / 常规三级，在总览面板与页头徽标持续可见。
- 同一批次重复标记只计一次；容量数据缺失时维持积压与风险得出的等级，不错误升级。
- 在批次档案或任务清单中标记处理完成后，提醒数量、档案状态和任务清单同步更新，并通过 localStorage 保持。
